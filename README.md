### 📌 Featured Projects

**🏈 NFL Draft Prediction** — *Data Science / GBDT ensemble*
LightGBM + CatBoost ensemble predicting NFL Draft selection from college combine data. Optuna-tuned (50 trials), 5-fold stratified CV, seed-averaged, with **leak-safe fold-internal target encoding** and missingness-as-signal features → **0.829 OOF ROC AUC**. *(GCI World 2026, University of Tokyo Matsuo Lab — leaderboard rank pending.)*

**⚖️ Verdex — Online Judge** — *Full-stack / SDE*
Full-stack competitive-programming judge: FastAPI + React/Vite, a compile-once/run-all execution engine, Docker-sandboxed code runner, deployed on AWS (EC2/ECR) with GitHub Actions CI and an automated test suite.

**🔬 DKL-BO — Deep Kernel Learning + Bayesian Optimization** — *Research*
CGCNN graph encoder + Gaussian Process surrogate driving Bayesian optimization; reaches the global optimum in ~3% of evaluations (**6.3× vs. random**, 30 seeds, Wilcoxon p≈0.002). *Research project — code under wraps; details on request.*

**🧪 Materia — Agentic Materials-Simulation Platform** — *Research / GenAI*
~26K-LOC platform: a 23-tool Gemini function-calling agent orchestrating scientific simulations, with a FastAPI + React 19 + Electron desktop app, Celery/Redis distributed workers, and PostgreSQL. *Research project — link on request.*

**🤖 Agentic RAG Chatbot** — *AI Engineering*
LangGraph multi-tool agent with streaming responses and persisted conversational memory, answering over a retrieval corpus with tool-augmented reasoning.

**📊 Customer Segmentation** — *Data Analytics*
SQL + Power BI value/promo segmentation with an executive summary and a retention playbook — turning raw customer data into an actionable business narrative.

**📉 Telecom Churn Retention** — *Data Analytics*
Value-weighted churn model over 100K customers with a decile lift table, cumulative-gains analysis, and an expected-value targeting model → a **projected $2.07M/yr net benefit (2.1× ROI)** with sensitivity analysis. *(GCI World 2026 — dollar figures are modeled projections, not measured outcomes.)*
